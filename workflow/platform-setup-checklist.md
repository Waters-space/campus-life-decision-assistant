# 平台配置清单

## 知识库

- [ ] 分别创建餐饮、快递、空闲教室和二手教材知识库。
- [ ] 清洗名称、别名、时间、地址和来源字段。
- [ ] 检查切片并测试正常命中、错别字、无结果和过期资料。
- [ ] 不上传真实密钥、管理员数据或无授权个人信息。

## 六个工作流

- [ ] 餐饮、快递、空闲教室、二手教材工作流分别关联对应知识库。
- [ ] 时间工作流连接已托管并可开机自启的时间服务。
- [ ] 路线工作流完成起点和终点 POI 精确匹配，再调用步行路线 API。
- [ ] 每个 HTTP 节点设置超时、异常分支和可读错误。
- [ ] 每个工作流独立运行测试并记录版本。

## Skill 转换

- [ ] 发布六个工作流。
- [ ] 为每个工作流生成 Skill，UUID 只填在部署配置中。
- [ ] `authentication.md` 使用 BearerAuth，真实 Key 使用平台变量。
- [ ] `workflowrun.md` 包含完整 Request、Responses、Success Schema 与 Security。
- [ ] Skill 描述明确适用场景、输入字段和不可推断内容。

## 智能体

- [ ] 挂载六个 Skill。
- [ ] 使用 `system-prompt.md` 的路由、时间、路线和事实边界规则。
- [ ] 分别测试单 Skill、时间加业务、多业务联动和路线失败场景。
- [ ] 发布后把公开 WebChat 地址写入前端 `.env`，不修改组件源代码。

## 前端与服务端

- [ ] `VITE_PRIMARY_AGENT_URL` 与 `VITE_USED_BOOK_AGENT_URL` 指向正确环境。
- [ ] MaaS、地图和其他 Key 只存在于服务器或平台安全变量。
- [ ] 管理端内部码使用长随机值，运行数据未进入 Git。
- [ ] 完成 `pnpm check`、`pnpm test` 和 `pnpm build`。
